One line, one star: a review of Monday written as if Monday were a restaurant. Waited all weekend for a table, got Monday, cold coffee, a rude waiter, and a bill that lasts five days. The program writes the single line to `entry.txt` (UTF-8, 114 characters, 22 words, no trailing newline).

> One star. Waited all weekend for a table, got Monday. Cold coffee, a rude waiter, and a bill that lasts five days.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-monday-out python3 main.py
```
